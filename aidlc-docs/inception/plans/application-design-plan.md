## 1. 設計スコープ
要件（`requirements.md`）とストーリー（`stories.md`）に基づき、以下の高レベル構成を設計する：
- 公開フロントエンド（React/TS）
- 管理フロントエンド（CMS・スマホ最適化）
- バックエンドAPI（Python・サーバーレス）
- 認証（Cognito）
- データ層（DynamoDB）／メール（SES）／配信（S3+CloudFront）

## 2. コンポーネント初期案（詳細は回答後に確定）
| コンポーネント | 高レベル責務 |
|---|---|
| PublicWebApp | 公開サイトのUI（紹介/規約/ブログ/お知らせ/カレンダー/募集/問い合わせ） |
| AdminWebApp | 管理CMSのUI（投稿・カレンダー登録・問い合わせ管理・アカウント招待） |
| ContentService | ブログ・お知らせ・静的ページのCRUD/公開管理 |
| CalendarService | 活動予定のCRUD/公開 |
| ContactService | 問い合わせ受付・保存・メール通知・履歴管理 |
| AuthService | 認証/認可・招待（Cognito連携）・ロール管理 |
| MediaService（将来） | 画像管理（初期は無効、Phase後） |
| PublicApiGateway / AdminApiGateway | 公開/管理APIの入口（認可分離） |
