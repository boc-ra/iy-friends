## 参考: ドメインと AWS 運用費の概算（Q15 への回答）

> 為替は 1 USD ≒ 150 円で換算した概算です。実際の金額は登録業者・時期により変動します。

### ドメイン費用（年額）
| 選択肢 | 内容 | 概算費用 |
|---|---|---|
| A. 現行 `iy-o-endan.com` を引き継ぐ | すでに取得済みのドメインなら、**更新料のみ**。AWS 側（Route 53）へ DNS を向け直すだけ | `.com` 更新：**約 1,500〜2,500 円/年**（＋移管する場合は初回のみ移管料が同程度） |
| B. 新しいドメインを取得 | 例：`iy-friends.com` など新規取得 | `.com` 新規：**約 1,500〜3,000 円/年**。`.jp` は **約 2,000〜4,000 円/年** |

補足：現行サイトは無料HP作成サービス（hp-ez.com）上で運用されています。`iy-o-endan.com` が**クラブ側で取得・保有しているドメイン**か、サービス提供元の管理下かによって、引き継ぎの可否・移管手続きが変わります。**A を選ぶ場合は「ドメインの登録業者アカウント（お名前.com 等）にログインできるか」をあわせて教えてください。**

### AWS 月額運用費（Q18＝コスト最優先 を反映した想定構成）
小規模クラブ向けに、**サーバーレス構成（S3 + CloudFront + Lambda + API Gateway + DynamoDB + Cognito + SES）** を想定した概算です。月数千〜1万PV程度なら：

- **月額 約 150〜750 円（約 1〜5 USD）** に収まる見込み（多くはほぼ無料枠内）
- 固定でかかるもの：Route 53 ホストゾーン **約 75 円/月（$0.50）**、独自ドメイン利用時の証明書（ACM）は**無料**
- 画像を本格的に扱い始める・アクセスが増えると、S3/CloudFront の転送量に応じて微増

> ※上記はあくまで概算です。確定した構成・料金は Construction フェーズのインフラ設計で提示します。
