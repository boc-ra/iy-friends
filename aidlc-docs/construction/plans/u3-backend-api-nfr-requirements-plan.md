## Q-N1: データ保護（DynamoDB バックアップ）
データのバックアップ方針は？（子供・保護者に関わる問い合わせ等を扱うため）

A) PITR（ポイントインタイムリカバリ：最大35日の継続バックアップ）を有効化（AI推奨・低コストで安心）

B) 定期バックアップのみ（日次スナップショット）

C) おまかせ

X) Other（自由記述）

[Answer]: A（「安いほう」の指示により最低コスト構成を採用。小規模データではPITRが日次スナップショット運用より安く・簡単・安全）

B) より速い目標を設定したい（`[Answer]:` に希望を記載）
